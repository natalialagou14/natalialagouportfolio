# Natalia Lagou — Product Design Portfolio

Product Designer based in Athens. Selected work from the **BOX merchant app**: order acceptance, ingredient availability, and the design system underneath both.

## Case studies

| Project | What it covers |
|---|---|
| [Incoming Orders](orders/index.html) | The merchant-side order flow: three fulfilment channels, five order states, and the five minutes a shop has to answer. |
| [Ingredient Availability](ingredients/index.html) | Letting a shop take an ingredient off the whole menu in one action, and see exactly how much of the menu it changed. Mobile and desktop. |
| [BOX Design System](design-system/index.html) | The Figma library behind the app: typography and layout tokens, atomic structure, and components with their real states. |

## Viewing

The site is plain static HTML/CSS with a little vanilla JavaScript, no build step.

- **Online:** enable GitHub Pages (Settings → Pages → Deploy from branch → `main` / root) and open the published URL.
- **Locally:** open `index.html` in a browser.
